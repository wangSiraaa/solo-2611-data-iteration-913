# slabwater — 分块标高接缝与有开闸上限的蓄水核验

纯合成离散模型，仅用于可复现的规则核验，**不用于现场水利判断**。

实现为 Python 3.11 独立库（仅标准库 + SQLite），分三层：

| 模块 | 职责 |
| --- | --- |
| `slabwater/catalog.py` | 独立、只追加的分块标高目录；批次校验、冻结切面、逐格来源 |
| `slabwater/solver.py` | 水位/蓄水计算；按出口集合搜索可行计划 |
| `slabwater/publisher.py` | 发布、幂等复读、拒绝留证、核计划、重开 |

## 目录（Catalog）

固定 `H×W` 格面，每块给出 `tile_id`、`revision`、原点 `(row,col)`、整数矩形与高度。一次批次：

- 可同时给出多块，**按 `tile_id` 替换**；批次未提及的块沿用上一版。
- 批次整体校验，全部通过才追加一个新版本；失败则**不落任何版本**，旧产品不变。
- 校验项：矩形越界、`tile_id` 重复、同一 `(tile_id,revision)` 内容被改写（immutable）、
  切面**未完整覆盖**（`coverage_gap`）、**重合格高度不一致**（`overlap_mismatch`）、
  格高超过上限 `C`（`height_above_ceiling`）。
- 每版冻结 `heights`、`elevation_hash` 与逐格 `sources`（来自哪块、块的修订、行列局部坐标）。

历史版本可随时 `get_slice(version)` 读取，发布端据此独立取标高，互不影响。

## 水位模型（Solver）

四邻移动，整数高度。对已打开的出口集合：

1. 一格到某打开出口的**排水门槛** = 路线经过的所有格高与出口门槛 `sill` 的最大值。
2. 该格水位 = `min(C, 所有打开出口门槛的最小值)`；无任何出口可达时为 `C`。
3. 蓄水 = 水位 − 本格高（逐格一致计算）。

这不是最短路求和，而是**最小化最大瓶颈**（minimax）的 Dijkstra：扩展边时取
`max(当前瓶颈, 邻格高)`。因此**不能直接用最低出口门槛**——路径上的高堤仍会抬升水位
（见测试 `test_lowest_sill_alone_is_not_enough`）。

### 两种搜索策略

- `recompute`：对每个候选出口集合跑一次多源 minimax Dijkstra。直接、易证正确。
- `reuse`：每个出口只算一次逐格瓶颈图，集合内逐格取**最小**组合。候选集合多时更省。
  瓶颈图只对**某一冻结切面**有效。

`BottleneckCache` 以 `elevation_hash` 为键：切面一旦改变（新版本、标高修订），
下次查询立即**清空失效**并计数 `invalidations`。在 12×12、8 出口压力样例中
（最多开 8 个，共 256 个集合）：

| 策略 | Dijkstra 次数 | 耗时 | 结果 |
| --- | --- | --- | --- |
| reuse | 8（每出口一次） | 0.028s | 与 recompute 完全一致 |
| recompute | 256 | 0.119s | — |

选择建议：候选集合少、或只需核一个既定集合 → `recompute` 更直接；候选集合多且同一
切面反复查询 → `reuse`。任何标高修订后不要跨切面复用瓶颈图，交给缓存自动失效。

搜索按“集合大小升序、再按出口 id”确定性枚举，因此同输入必然得到同一产品（无需最小开闸数）。
`stop_on_first=True` 命中即返回；`False` 则遍历全部并在可行集合中取总蓄水最小者，同时保留全部尝试。

## 发布（Publisher）

请求需给候选出口、`opens`（最多开启数，未要求必须开满）、以及 `total_max` 与 `cell_max`
（若干指定格蓄水上限）。消费端只读**已冻结**的 `source_revision` 切面。

- **成功**：写正式 `plans` 行，产品含开启出口、逐格水位/蓄水、总量、可复查的
  `elevation_source`（版本、`elevation_hash`、块清单）与 `artifact_hash`。
- **拒绝**：不写正式计划；保存真实尝试的**穷尽证据**：每个候选集合的开口、总量、指定格蓄水
  与违反的约束（`total` / `cell`），以及 `exhaustive=true`。可直接下载核对。
- **错误**（未知版本、出口越界/不在边界、请求非法）：记错误结果，同样不写正式计划。
- **幂等**：同一申请 `id` + 同一输入 → 原样复读首次结果（成功返回同一 `plan_id` 与工件；
  失败返回同一证据）。同一 `id` 换输入 → `idempotency_conflict`，绝不静默覆盖。
- **版本隔离**：新标高版本不改写旧 `plans` 行；`get_plan`/`verify`/`reopen` 均按产品内
  冻结的版本与哈希核验。

### 读标高 / 核计划 / 发布 / 重开入口

```python
from slabwater import Catalog, Publisher

catalog = Catalog("catalog.db", height=1, width=5, ceiling=6)
publisher = Publisher("plans.db", catalog)

catalog.apply_batch([...tiles...])          # 追加切面版本
publisher.read_elevation(version=1)         # 读标高（含逐格来源）
publisher.publish(request, default_outlets=[...])  # 实际发布
publisher.verify(plan_id)                   # 核计划（重算并重搜索）
publisher.reopen(plan_id)                   # 重开已存工件
```

命令行：

```bash
python3 -m slabwater run materials/772/input.json --db-dir /tmp/run772
python3 -m slabwater verify /tmp/run772 <plan_id>
python3 -m slabwater reopen /tmp/run772 <plan_id>
```

## 样例核对（materials/772）

- 初版 `[0,4,1,4,0]`，双口全开：水位 `[1,4,4,4,3]`，蓄水 `[1,0,3,0,3]`，总 7，中格 3。
  A1（总量≤7、中格≤2）必拒：没有任何集合同时满足，证据穷尽列出（含双开的 `cell` 违例）。
- 降右侧堤后 `[0,4,1,2,0]`，双口全开：水位 `[1,4,3,3,3]`，蓄水 `[1,0,2,1,3]`，总 7、中格 2。
  A2（≤7、中格≤2）成功，开启 `L,R`。
- A3 只允许开 1 口：`L` 总 10、`R` 总 10，均超总量 7（`R` 虽满足中格≤2），故拒绝。
- `invalid_correction` 使重合格 `(0,2)` 出现 1 与 2，冲突 → 整版拒绝，版本仍为 `[1,2]`。

# 跨区核验（slabwater/xregion.py）——只开放边界地形块的分区蓄水核实

两家（或多家）展馆各保管合成格面的一个矩形区（由水平/垂直接缝切出），合约允许
另一馆核对**沿分界线的结果**与**各自展区的总蓄水量**，但禁止导出内部逐格高度、
坐标或能还原它们的逐格表。本层沿用 solver 的冻结切面、四邻通道、最低瓶颈与水位
上限 `C`，在此之上给出三块能力：**分馆匿名水力产品**、**总馆组合求值与开闸搜索**、
**可复查的证书**。格面 ≤32×32，底高 0..63，每条区界 ≤12 个端口。

## 模型固化

- 接缝是**封死的**：跨区相邻格只在“公开的相邻端口对”处接通，且接通要付**过缝门槛**
  `sill`——路线瓶颈取 `max(路线格高, sill, 出口排水水位)`，与 solver 的取 max 规则一致。
- 出口只能放在**公开的边界端口**；每个候选出口带指定排水水位（指定端口水位）。
- 任何一格水位 = `min(C, min over 打开出口 of 路线瓶颈)`；无出口可达时为 `C`。

## 分馆：匿名水力产品（`build_product` → `RegionProduct`）

把本区按水位做并查集（Kruskal 重建树）：归并点水位即两侧打通的最低瓶颈。然后
**把不含端口的整棵子树压成一个匿名块**——内点的数量与高度频数按水位和连通分量
合并，只留 64 桶直方图。产品里只有三种结点：

| 结点 | 内容 | 是否公开 |
| --- | --- | --- |
| `P` 端口块 | 边界端口坐标与块高 | 公开（边界地形块本就开放） |
| `B` 匿名块 | 同一水位连通分量合并后的高度频数 | 匿名（无坐标、无逐格高度） |
| `N` 归并点 | 两侧打通的水位 | 结构信息（查询合同固有） |

外加合同允许公开的：本区面积、总底高、全区高度频数、端口两两最低瓶颈表。
产品回答两类查询：

- **连通**：端口 p、q 在水位 w 连通 ⟺ 其归并点水位 ≤ w（查瓶颈表即可）。
- **库容**：给定一组端口排水水位，两遍树 DP（子树最浅源 + 祖先继承值）逐结点算
  水位；匿名块内所有内点共享同一继承水位，用前缀和 O(1) 求 `Σ max(0, L−h)`。

**匿名性论证**：产品不含内部逐格高度与坐标；它泄露的任何信息（面积、总底高、按
水位/分量合并的频数、端口间瓶颈、任意端口水位组合下的库容）都是合同允许或两类
查询本身就能问出来的——产品只是“查询接口的紧致证书”，不做密码学保密。签发确定
（同图同版本必得同字节），可 JSON 序列化后在多家总馆重复使用。

## 总馆：全局归并树 + 两阶段求值（`Curator`）

总馆只持各区产品与公开接缝（相邻端口对 + 门槛），**从不接触分馆内部块**：

1. **拼全局归并树**：三类顶点——端口（权重=公开块高）、接缝虚拟点（权重=门槛）、
   区内归并虚拟点（从产品树抽出，权重=归并水位，连到各含端口子树的一个代表端口）。
   按权重激活做并查集，得到全局树；任意两端口的最低瓶颈 = 树上最近公共祖先水位。
2. **求水位**：给定开闸方案，端口水位 = 全局树上多源 minimax（无出口分量取 `C`）。
3. **求库容**：把求得的各端口水位回代各区产品，独立求和。

为什么不能“每区只访问一次”：**水路可能离开一个区又从另一端口进来**。两阶段在
数学上是严格的：对区内任意格 c 与任意出口 o，跨区最低瓶颈满足
`B(c,o) = min over 本区端口 p of max(B_区(c,p), B_全局(p,o))`（首条离区路径分解），
因此 `L(c) = min_p max(L(p), B_区(c,p))`——先全局求端口水位、再分区独立求库容，
结果与整图直接求解逐格一致（`test_four_region_composite_matches_full_solver` 在
32×32 四区上逐组出口组合核对；审核小图见下）。

**开闸方案搜索**（`find_scheme`）：候选出口（各带指定排水水位）的子集枚举，出口
数 ≤ `opens`，要求各区水量落在核准 `[下界, 上界]`、指定端口水位落在给定区间。
库容关于开闸集合单调不增，由此得到两个立即判负（全关即低于下界 / 候选全开仍高于
上界）与下界剪枝；失败时保留全部已评估尝试作为穷尽证据（`exhaustive`），成功时
返回首个可签方案。

## 证书、版本与复查

- `issue_certificate` 产出证书：各区 `(region, version, product_hash)` 向量、公开
  接缝、开闸方案、算得的分区水量与端口水位、判定结果与 `cert_hash`。
- **分馆可单独换版**：产品按 `(region, version)` 归档；旧证书仍按其实际搭配的各区
  产品复查（`recheck_certificate` 重算并比对，篡改任一数字即失败）。
- **复开时可移走分馆内部块**：复查与求值的全部输入只有产品 + 公开接缝。
- **审核小图**：发布前用完整旧求解器（`full_levels`/`full_volumes`，整图 minimax，
  非接缝的跨区相邻一律封死）逐出口组合比对产品结果；`tests/test_xregion.py` 对
  200 张随机小图（≤5×5、≤4 区）做了 5000+ 项一致性核对。

## 两个例题（`python3 -m slabwater xregion-examples` 复算）

**例1（一行切左右两区）**：左 `[0,3,0]`、右 `[0,0]`，`C=4`，出口仅在右端、门槛 0，
接缝门槛 0，左区仅最右格有接缝端口。开口后左区水量 **3**；改成左 `[0,0,3]`，面积、
左区高度频数、总底高都不变，水量变 **6**——`[0,3,0]` 里高堤贴着接缝端口，低格
被它挡住（匿名块 `{0:1,3:1}` 与端口并列）；`[0,0,3]` 里高堤本身就是端口，两个低格
合并成匿名块 `{0:2}` 共同受堵。面积/频数/总底高相同的这两张图，只有按（水位,连通
分量）合并的产品结构能区分：核准上限 4 时仅前者可签，上限 6 时两者都可签。

**例2（两条跨区通路、必须绕行回区）**：A 行 `[0,9,9,0]`（山脊）压着 B 行
`[0,0,0,0]`（走廊），四对接缝端口门槛 `(0,0,0,3)`，出口在 `(0,0)`。A 区右端格
`(0,3)` 的区内排水瓶颈是 9（翻山脊），但它可以**离开 A 区**（列3接缝付门槛 3）沿
B 走廊**再从列0接缝回到 A 区**出水口——水位 3，A 区蓄水 3。若按“每区只访问
一次”孤立求值，A 区报 9，错。门槛扫描：列3门槛取 `0,3,5,9,12` 时 A 区蓄水
`0,3,5,9,9`（门槛高过山脊后绕行不再划算）。

## 规模实测（Python 3.11，32×32，每界 11 端口）

| 场景 | 产品结点 | 签发 | 产品大小 | 单次求值 |
| --- | --- | --- | --- | --- |
| 平坦展区（3 种底高） | 1291（匿名块 624） | 12.7 ms | 144 KB | 库容查询 ~0.45 ms |
| 阶梯展区（64 级全现） | 985（匿名块 471） | 10.9 ms | 110 KB | 库容查询 ~0.41 ms |
| 四区组合（22 条接缝、43 端口） | — | 4 区共 11.1 ms | 全局树 0.6 ms | 每组出口组合 0.64 ms |

结点数以 `2×格数−1` 为上界；一套产品可反复承担大量出口组合审查，并可在多家总馆
间复制使用。
